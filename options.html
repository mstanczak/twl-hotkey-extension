TWL Hotkey Enabler

This extension re-enables keyboard shortcuts like Ctrl+C, Ctrl+V, Ctrl+A, and Ctrl+F on TWL web interfaces.

Features
Advanced Settings ▾

Specialized order number formatting for ERP → TWL workflows.

Prepended to the order number (default: o00).
Automates barcode scanner behavior after order paste.

Note: Settings are saved to your Chrome profile and update open TWL tabs automatically.
